# ai-instructions

Word技術手順書を編集・検証するための、単独で使えるAI指示書を管理しています。必要な指示書を開き、全文を利用環境へコピーし、対象の文書と作業条件を指定してください。

## 指示書一覧

| 目的 | 指示書 | 版 | 必須の入力 |
| --- | --- | --- | --- |
| 正式な書式規定に合わせて手順書を整備する | [Word手順書 フォーマット規定準拠・再整備・品質保証指示書](documentation/word_format_spec_compliance_instructions_v4.md) | 4.1 | 書式規定書（FORMAT_SPEC）、編集対象の手順書（TARGET） |
| 意味・書式・機能を保持して日英または英日へ翻訳する | [Word技術手順書 日英・英日翻訳／書式保全／品質保証指示書](documentation/word_procedure_translation_instructions_v1.md) | 1.2 | 翻訳元の手順書（SOURCE）、翻訳方向 |

ファイル名の `v4` / `v1` は既存リンクを保つための系列名です。適用する版・改訂日は各指示書の冒頭を確認してください。

## 使い方

1. 目的に合う指示書を1本選び、全文と入力文書を渡します。用語集、正式テンプレート、対象製品・版、画面の言語など、利用できる補助資料も指定します。
2. 利用環境で実際に読み取り・編集・保存・描画できる範囲を確認し、原本のコピーを編集します。モデル名だけでWordの操作能力や入力上限を判断しません。
3. 編集済みWord文書と検証報告を受け取り、総合判定・未確認範囲・残課題を確認します。未実施の検証や既知の不具合を残す文書は、完成品と区別した候補として扱います。

書式整備と翻訳の両方が必要な場合は、通常は書式整備、翻訳の順に別工程として実施します。前工程の成果物を次工程の入力とし、翻訳後の最終ファイルでも書式、目次、参照、全ページの表示を再確認します。2本の全文を同時に適用して、書式の変更と保持を競合させないでください。

### 書式整備の依頼例

```text
添付の規定書をFORMAT_SPEC、現行手順書をTARGETとして、
この指示書に従って実際に編集し、Word文書と準拠性検証報告を作成してください。
```

### 翻訳の依頼例

```text
添付の手順書をSOURCE、翻訳方向をJA_TO_EN（日本語から英語）として、
この指示書に従って実際に翻訳し、Word文書と品質検証報告を作成してください。
```

日英翻訳では、説明文・専門用語・略称を含む自然言語の日本語を残さないことが基本です。一方、実行に必要なパス・設定値・照合文字列を英訳して別の値へ変えてはいけません。日本語を含む固定文字列や画像などが残る場合は、指示書の基準に従い、未達事項または承認済みの例外として明示します。
